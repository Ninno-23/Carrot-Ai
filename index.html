Connect your AI provider

Carrot AI sends requests through your server. Provider credentials belong in server environment settings, never in this page.

  • Chat and study tools need AI_API_KEY, AI_API_URL, and an available AI_MODEL.
  • Image generation uses IMAGE_API_KEY, or AI_API_KEY when that token has image access, plus a permitted IMAGE_MODEL.
  • HTTP 401/403 errors mean the token, model permission, or provider quota needs attention.
  • On Render, add these in your Web Service Environment settings, then redeploy. For local use, set them in the server process environment.
